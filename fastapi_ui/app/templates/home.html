How it works

From raw files to grounded answers

Every collection runs the same retrieval-augmented pipeline on the engine side.

  1. Chunk Text is cleaned, denoised and split into overlapping token windows.
  2. Embed Each chunk becomes a dense vector stored in an IVF / HNSW index.
  3. Retrieve & rerank Nearest neighbours of your query are re-scored by a cross-encoder.
  4. Generate An LLM summarises the top passages into an answer you can rate.
