Conversational UI to search engine (with Q&A models)

Welcome to SSSUI (Simple Semantic Search UI)! 👋

This is a fully functional UI to RadLab Semantic Search Engine. This application may be helpful when you want to test LLM models combined with IR/Semantic Search (f.e. for RAG)/Conversational search.

Select an option from the navigation bar to use engine.

Some dev information

  • Azure Project with database used to store embeddings and similarity search
  • Azure Project with semantic search engine backend with full REST API handling
  • Azure Project with conversational UI providing this application
  • Azure Project with LLM API service provided as internal publicity available api
  • Azure Project with starter django-core for rest framework
