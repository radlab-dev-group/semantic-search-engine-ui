# Czat RAG dla pracownika – pakiet dla RadLab

1 listopada 2026

| Co | Gdzie | Jak otworzyć |
|---|---|---|
| Klikalny prototyp | `prototyp/czat-rag-radlab.html` | Otwórz w przeglądarce. Zaloguj się dowolnym loginem i hasłem. Przycisk „Dla RadLab” (lewy dolny róg) pokazuje scenariusz, mapę endpointów i braki w API. |
| Braki w API | `BRAKI-W-API.md` | Lista 13 braków z priorytetem; P0 to must have. |
| Frontend 0.1.0 | `frontend/` | Instrukcja w `frontend/README.md`. Z atrapą backendu: `docker compose up --build` w folderze `frontend`, potem http://localhost:8000 (hasło `demo`). |
| Zgłoszenia zmian (pełny opis) | `frontend/docs/zgloszenia-do-radlab.md` | CR-01…CR-19 z propozycją i kryteriami akceptacji. |

Prototyp działa bez internetu; z internetem ładuje fonty Inter i Newsreader z Google Fonts.
